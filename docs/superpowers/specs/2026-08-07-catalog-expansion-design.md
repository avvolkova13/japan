# Расширение demo-каталога KANSO

Дата: 2026-08-07

## Цель

Добавить в существующий demo-каталог KANSO пять дополнительных позиций с номенклатурой и характеристиками, сверенными с JapRise. Новые товары должны автоматически появиться в общем каталоге, фильтрах по категориям, карточках товара, избранном и корзине через существующую модель данных и компоненты.

JapRise используется только как справочник названий, категорий, объёмов и цен для демонстрационных записей. Его фотографии, тексты, дизайн и коммерческие заявления не переносятся.

## Изображения

Для каждой позиции на этапе реализации создаются две KANSO-версии:

- основная предметная фотография на прозрачном фоне для обычного состояния карточки;
- атмосферный кадр в единой clean-girl арт-дирекции для hover и галереи страницы товара.

На изображениях сохраняются реальные читаемые названия бренда и продукта только по доступному исходному визуальному ориентиру; случайные названия и вымышленные логотипы не добавляются. Фотографии JapRise не копируются и не подключаются напрямую.

## Техническое подключение

1. Добавить пять seed-записей в `src/data/demo-products.ts`.
2. Добавить для них записи в `src/data/product-image-manifest.ts`.
3. Положить новые изображения в `public/images/kanso/products/` с отдельными именами по ID.
4. Не менять компоненты каталога и страницы товара, если текущая модель данных полностью покрывает новые записи.
5. Проверить переходы на `/product/face-03` … `/product/hair-03`, избранное, корзину, фильтры Face/Hair и отсутствие дублей ID.

## Критерии готовности

- В каталоге отображаются все 25 demo-товаров.
- У каждого нового товара есть название, бренд, цена, объём, primary image и gallery/hover image.
- Основное изображение — предметное, без фона; атмосферный кадр появляется только в hover/галерее.
- Страница каждого нового товара открывается напрямую и не ломает существующие маршруты.
- Новые записи не представлены как реальные остатки, отзывы или подтверждённые коммерческие условия.
- `npm run build` проходит без ошибок.
