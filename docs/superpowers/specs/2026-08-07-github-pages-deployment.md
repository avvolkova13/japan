# Спецификация: публикация KANSO через GitHub Pages

## Цель

Сделать текущий интернет-магазин KANSO доступным по публичной ссылке, не меняя дизайн, контент и пользовательские сценарии.

## Решение

- Использовать GitHub Actions для сборки и публикации статического экспорта Next.js.
- Публиковать проект GitHub Pages в подпути `/japan/` репозитория `avvolkova13/japan`.
- Добавить единый helper для публичных путей, чтобы изображения, постер и видео корректно работали локально и на Pages.
- Оставить текущую ветку `codex/editorial-video-scroll` источником публикации.

## Критерии приёмки

- Production-сборка выполняется с `GITHUB_PAGES=true`.
- Страницы, изображения и видео используют URL с `/japan/` на Pages.
- GitHub Actions содержит отдельные build и deploy jobs.
- Публичный адрес: `https://avvolkova13.github.io/japan/`.
