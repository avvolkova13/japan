# Редакционный каталог KANSO

## Цель

Заменить текущую модульную сетку каталога на спокойную editorial-композицию по согласованному референсу: крупный заголовок, компактные фильтры и чередование небольших и крупных товарных блоков в единой сетке.

## Визуальная структура

- Верхняя часть каталога сохраняет текущую навигацию KANSO, но получает более собранную композицию с заголовком, коротким описанием и фильтрами.
- Фильтры категорий, брендов и сортировки располагаются в одну компактную строку/полосу и продолжают работать через URL-параметры.
- Товары выводятся editorial-рядом: несколько небольших карточек, затем крупные визуальные карточки, затем снова небольшие карточки. Ряды используют одну сетку и постоянный интервал 16 px.
- Крупные карточки занимают несколько колонок, но их изображения, подписи и цены выравниваются с соседними рядами.
- В карточках остаются только название и цена; серые служебные подписи бренда и объёма не показываются.
- Изображения с фоном заполняют всю область карточки; изображения товара без фона остаются аккуратно вписанными в голубую поверхность.
- Hover-состояние использует второе изображение с мягким crossfade/scale без появления голубых краёв.

## Поведение

- Фильтрация и сортировка не меняют архитектуру данных и продолжают работать через `searchParams`.
- Карточки остаются ссылками на существующие страницы товаров.
- Быстрое добавление в корзину сохраняется.
- На мобильных ширинах editorial-ряд превращается в последовательную адаптивную сетку без горизонтального переполнения.
- Для hover-анимаций и появления карточек добавляется `prefers-reduced-motion` fallback.

## Ограничения

- Не добавлять новые зависимости.
- Не менять визуальную систему главной страницы.
- Не придумывать новые бизнес-данные, реальные остатки или юридические сведения.
- Не заменять существующие изображения без необходимости.

## Затрагиваемые файлы

- `src/app/catalog/page.tsx` — структура рядов и порядок карточек.
- `src/components/catalog-product-card.tsx` — семантика карточки и hover-слои.
- `src/components/catalog-toolbar.tsx` — сохранение работающих фильтров и сортировки.
- `src/app/globals.css` — editorial-сетка, размеры, выравнивание, responsive и motion.

## Критерии готовности

- Каталог визуально следует согласованной editorial-структуре вместо текущей модульной сетки.
- Между карточками в desktop- и mobile-сетках ровно 16 px.
- Все товарные подписи и цены выровнены по сетке.
- Фильтры и сортировка сохраняют текущую функциональность.
- `npm run lint`, `npm run typecheck`, `npm run build` и `git diff --check` завершаются без ошибок.
