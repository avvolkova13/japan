# Страница товара KANSO: галерея и информация

## Цель

Переделать страницу товара в компактный editorial-интерфейс по согласованному референсу: вертикальные миниатюры слева, крупная галерея в центре и закреплённая информация о товаре справа.

## Desktop-композиция

- Слева — вертикальная лента миниатюр всех изображений товара.
- В центре — крупная активная фотография с аккуратным заполнением области без голубых краёв для полноформатных изображений.
- Справа — бренд, название, цена, объём, количество, кнопка добавления в корзину и ссылка на корзину после добавления.
- Информационная колонка остаётся компактной и доступной при просмотре галереи.
- Ниже — раскрывающиеся блоки «Описание», «Детали», «Состав и применение».

## Управление галереей

- Перелистывание поддерживает drag мышью, touch swipe, колесо мыши, клавиши ArrowLeft/ArrowRight и кнопки навигации.
- Переход между изображениями использует мягкий slide с лёгкими scale/fade-переходами.
- Активная миниатюра визуально выделяется и синхронизируется с основным изображением.
- Галерея не должна перехватывать вертикальную прокрутку страницы без необходимости.
- При `prefers-reduced-motion: reduce` переходы становятся мгновенными или минимальными.

## Mobile-композиция

- Сначала показывается крупная горизонтальная галерея со swipe.
- Миниатюры превращаются в компактный горизонтальный ряд или индикатор.
- Информация о товаре располагается ниже галереи обычным вертикальным потоком.
- Кнопка покупки остаётся доступной и не выходит за ширину экрана.

## Ограничения

- Сохранить текущие цвета и типографическую систему KANSO.
- Сохранить работу корзины, количество товара и существующие маршруты.
- Использовать текущие изображения и данные товара.
- Не добавлять новые зависимости.
- Не менять главную страницу и каталог в рамках этой задачи.

## Затрагиваемые файлы

- `src/components/product-detail.tsx` — структура галереи, управление активным слайдом и взаимодействия.
- `src/app/globals.css` — desktop/mobile layout, thumbnails, transitions, focus и reduced-motion.
- `src/app/product/[id]/page.tsx` — только если потребуется передать дополнительные данные галереи.

## Критерии готовности

- Галерея перелистывается всеми заявленными способами.
- Миниатюры и основное изображение синхронизированы.
- Информация и кнопка покупки не теряются при взаимодействии с галереей.
- Страница адаптивна на desktop и mobile.
- `npm run lint`, `npm run typecheck`, `npm run build`, `git diff --check` и функциональная проверка локальной страницы проходят без ошибок.
