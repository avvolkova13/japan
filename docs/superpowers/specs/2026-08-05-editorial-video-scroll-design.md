# Editorial Video Scroll — Design Specification

## Цель

Преобразовать существующий editorial-блок главной страницы KANSO в scroll-сцену с локальным зацикленным видео. Исходное расположение объектов на входе в секцию сохраняется: медиа остаётся слева, заголовок, описание и кнопка — справа. Во время прокрутки видео раскрывается до полноэкранного состояния, поверх него появляются тонкая линия и два согласованных текста, после чего секция отпускает страницу и продолжается обычный скролл.

## Визуальный принцип

Анимация использует механику референса Zetta Joule на уровне взаимодействия, но получает самостоятельную арт-дирекцию KANSO. Начальное двухколоночное состояние переходит в закреплённую полноэкранную сцену. Масштабирование происходит непрерывно и привязано к прогрессу прокрутки; оно не запускается отдельным таймером. Скругление медиа уменьшается до нуля по мере раскрытия. Текстовый слой появляется только после того, как видео почти заняло экран.

## Видео

- Формат: MP4, H.264, 16:9, без звука.
- Ориентир по длительности: 15–18 секунд.
- Поведение: `autoplay`, `muted`, `loop`, `playsInline`.
- Файл хранится локально в `public/videos/kanso/`, без зависимости от внешнего CDN.
- Видео собирается из 8–10 сгенерированных кинематографичных кадров с мягким движением камеры, аккуратными cross-dissolve и match-cut переходами.
- Визуальная непрерывность: одна перламутровая баночка крема без выдуманного брендинга и бизнес-утверждений; одна героиня; молочно-бежевые, прохладно-голубые и светло-серые оттенки; мягкий дневной свет; минималистичная японская среда.

## Режиссура ролика

1. Макро: молочная текстура крема смешивается в чистой светлой лабораторной среде.
2. Перламутровая баночка движется по минималистичной линии упаковки.
3. Упакованный крем перемещается к спокойному японскому beauty-магазину.
4. Девушка берёт эту же баночку с полки и покупает её.
5. В светлой домашней ванной девушка наносит крем на лицо.
6. Финальный крупный план текстуры визуально соединяется с первым кадром, создавая мягкий бесшовный loop.

Кадры должны ощущаться как единый журнальный фильм: спокойный темп, чистая композиция, естественная кожа, без агрессивной рекламы, медицинских обещаний и демонстрации неподтверждённых свойств продукта.

## Scroll-сценарий на desktop

Секция получает высоту `220svh`, внутри которой работает закреплённый viewport.

- `0–18%`: сохраняется исходная двухколоночная композиция; видео воспроизводится слева, текстовый блок остаётся справа.
- `18–55%`: секция закрепляется; правый editorial-текст мягко уходит; видео непрерывно расширяется из исходной позиции до размеров viewport; скругление уменьшается до нуля.
- `55–68%`: полноэкранное видео стабилизируется, без резкого скачка масштаба.
- `68–82%`: проявляется тонкая горизонтальная линия, затем синхронно появляются две текстовые зоны.
- `82–92%`: полноэкранная композиция удерживается для чтения.
- `92–100%`: закрепление заканчивается, и следующая секция продолжает обычный вертикальный скролл.

Анимация интерполируется напрямую из фактического прогресса секции. Она должна одинаково корректно работать при медленной прокрутке, резком скролле, прокрутке назад и изменении размера окна.

## Текст поверх видео

Левая зона над линией:

> ПУТЬ ОДНОЙ ФОРМУЛЫ

Правая зона над линией:

> От первого прикосновения — к привычке, которая остается.

Текст используется дословно. Вторая фраза отображается курсивом. Цвет — светлый нейтральный с достаточным контрастом к видео; при необходимости применяется очень мягкое затемнение нижней части кадра без заметного градиентного эффекта.

## Структура компонента

- Новый клиентский компонент отвечает только за scroll-прогресс, видео и overlay.
- Существующая ссылка «Читать историю», заголовок и описание сохраняют текущие назначение и расположение в начальной композиции.
- Главная страница подключает компонент вместо текущего статичного изображения внутри editorial-секции.
- CSS отвечает за геометрию, responsive-состояния и CSS custom property прогресса; JavaScript обновляет только нормализованный прогресс и состояние reduced motion.
- Сторонняя animation-зависимость не добавляется: для этой одной сцены достаточно `requestAnimationFrame`, чтения `getBoundingClientRect()` и CSS-интерполяции.

## Responsive и reduced motion

- На планшетах сохраняется раскрытие, но высота scroll-секции уменьшается до `180svh`, а текстовые зоны получают более компактную типографику.
- На мобильных исходный блок остаётся вертикальным. Видео не закрепляет страницу на несколько экранов: показывается широким статичным блоком с обычным воспроизведением, а линия и оба текста располагаются непосредственно под видео.
- При `prefers-reduced-motion: reduce` отключаются pinning и интерполяция размера. Видео остаётся в исходной композиции и показывает poster-кадр без autoplay; все тексты доступны без прокрутки-сценария.

## Доступность и устойчивость

- Видео декоративное и получает пустое текстовое описание; смысл секции остаётся доступен через существующий заголовок и текст.
- Контент не блокирует клавиатурную навигацию и не меняет порядок фокуса.
- При ошибке загрузки видео показывается текущий статичный кадр `/images/kanso/editorial-ritual.png`.
- Scroll-обработчик пассивный, обновления объединяются через `requestAnimationFrame`, слушатели удаляются при размонтировании.
- Layout shift исключается заранее заданным aspect ratio и размерами контейнера.

## Проверка результата

- Desktop: исходная сетка визуально совпадает с текущим блоком; видео раскрывается без рывка и соседние секции не накладываются.
- Scroll: поведение проверяется при движении вниз и вверх, быстрых wheel-жестах и переходе через границы pinning.
- Видео: локальный MP4 загружается, воспроизводится без звука, зацикливается и не требует пользовательского клика.
- Mobile: нет горизонтального скролла, зависшего pinning и перекрытия текста.
- Accessibility: `prefers-reduced-motion` отключает сложную анимацию; интерактивные элементы сохраняют фокус и доступные имена.
- Regression: `npm run typecheck` и `npm run build` завершаются без ошибок.
