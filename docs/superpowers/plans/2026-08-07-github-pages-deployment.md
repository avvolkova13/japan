# План: публикация KANSO через GitHub Pages

## Этап 1. Конфигурация статического экспорта

- Настроить `output: "export"`, `trailingSlash` и подпуть `/japan/` только для GitHub Pages.
- Отключить оптимизацию `next/image`, необходимую для статического экспорта.
- Нормализовать пути к публичным изображениям и видео.

## Этап 2. Автоматическая публикация

- Добавить workflow GitHub Actions.
- В workflow запускать typecheck, lint и production build.
- Передавать собранную папку `out` в GitHub Pages.

## Этап 3. Проверка и публикация

- Выполнить локальные проверки и собрать production-версию.
- Проверить наличие `/japan/` в ссылках ассетов и наличие видео в `out`.
- Закоммитить и отправить изменения в GitHub.
- Проверить статус workflow и публичный адрес.
