# План: расширение demo-каталога KANSO

## Цель

Добавить 5 сверенных с JapRise demo-товаров в существующую модель каталога KANSO, подготовить для каждого предметное изображение без фона и атмосферный кадр, затем проверить каталог и страницы товаров.

## Этапы

### 1. Подготовка изображений

- Создать по две KANSO-версии изображения для каждого нового товара.
- Проверить прозрачность предметных PNG, безопасные поля, пропорции и читаемость упаковки.
- Сохранить файлы в `public/images/kanso/products/` с именами, связанными с ID товара.

### 2. Данные и manifest

- Добавить seed-записи `face-03`–`face-06` и `hair-03` в `src/data/demo-products.ts`.
- Добавить primary/secondary/gallery-ссылки в `src/data/product-image-manifest.ts`.
- Сохранить статусы demo-каталога: `available: false`, `availability: catalog-preview`.

### 3. Функциональная проверка

- Проверить общее количество 25 товаров.
- Проверить фильтры Face и Hair.
- Открыть все 5 новых маршрутов `/product/...`.
- Проверить избранное, корзину и hover-кадры.

### 4. Визуальная и техническая проверка

- Проверить предметные изображения без шахматного/серого фона.
- Проверить атмосферные кадры только в hover/галерее.
- Запустить `npm run build`.
- Устранить только регрессии, связанные с этим добавлением.
