# План реализации информационных страниц

1. Создать типизированный источник контента для семи маршрутов.
2. Добавить общий server component с metadata и `notFound()` для неизвестных slug.
3. Добавить адаптивные стили без изменения существующей десктопной главной.
4. Заменить footer-заглушки реальными `Link`.
5. Проверить маршруты, навигацию, accessibility, 320/390/768/1024/1440 px, lint, typecheck и production build.
